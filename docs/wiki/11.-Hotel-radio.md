# Hotel radio

The Radio app plays live stations and SoundCloud tracks for signed-in players. Open it from the start menu or go to `/radio`.

## Who does what

- **Players** listen, and can suggest a station or track. Each player can have 3 suggestions waiting at a time.
- **DJs** add things straight to the radio, review suggestions, remove anything, and pick what's **on air**. Everyone listening to the on-air pick switches when a DJ changes it.
- The hotel's top rank is always a DJ.

## Setting it up in Housekeeping

Go to **Hotel → Radio**.

1. Press **DJs and suggestions**.
2. Pick the roles that count as DJs. On PlusEMU this lists every role, so you can pick roles that share a rank with regular players, like Events Staff.
3. Turn player suggestions on or off.

The same page lists everything on the radio and every suggestion. Waiting suggestions show first, with a count in the menu.

Staff need the `manage_radio` Housekeeping permission to open this page.

## What links work

- SoundCloud tracks and sets, such as `https://soundcloud.com/artist/track`.
- Live stations: the stream address itself, over `https://`, such as `https://ice1.somafm.com/groovesalad-128-mp3`. The server checks that the address is public and actually plays audio before saving it.
