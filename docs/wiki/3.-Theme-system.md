# Theme system

Themes live in `resources/themes/`. There are three: `lucadoos`, `atom` and `dusk`. If a theme lacks a view, Atom uses the view of the parent theme set in `config/theme.php`.

## LucadoOS

`lucadoos` is the default theme. It shows the hotel as a desktop: every page opens in its own window, with a taskbar, a Start menu, window snapping and neon waves over the wallpaper. Players pick the wallpaper, the waves and light or dark mode under Personalize in the Start menu. These choices stay in their browser.

LucadoOS uses the `atom` views for the pages themselves, so every page and feature works the same way.

It builds into its own folder, `public/build-lucadoos`, so building another theme never breaks it.

LucadoOS™ is a trademark of Jacob Lucado.

## Pin a theme

`CMS_THEME` in `.env` pins the theme. It wins over the `theme` website setting and over `atom:install --theme`, so an installer that asks for another theme still gets this one. `.env.example` pins `lucadoos`. Remove the line to pick the theme in Housekeeping instead.

Themes only apply in full mode. In [headless mode](10.-Headless-mode.md) there is no theme.

## Switch theme

1. Build the theme first:

   ```bash
   npm ci
   npm run build:lucadoos
   npm run build:atom
   npm run build:dusk
   ```

   Build each theme that must stay available. `php artisan build:theme` lets you pick one.

2. Change the `theme` value in Housekeeping, under CMS settings. If `CMS_THEME` is set in `.env`, change it there instead.

For development, use `npm run dev:lucadoos`, `npm run dev:atom` or `npm run dev:dusk`.

## Create your own theme

1. Create the theme:

   ```bash
   php artisan make:theme my-theme
   ```

   The command comes from the `qirolab/laravel-themer` package.

2. Read the files it creates. Add the `dev:my-theme` and `build:my-theme` scripts it prints to `package.json`.
3. Copy the asset paths and manifests from the bundled Vite configuration.
4. Say no when it offers to replace the authentication scaffolding. Atom's own login and controllers support the hotel's features.
5. Build your theme and set its folder name as the `theme` value in CMS settings.
6. Test login, registration, user settings, the client, the shop and Housekeeping.

If you change settings in the database, see [changing settings](README.md#changing-settings).
